# Markdown Tables for Flarum 2.x

![License](https://img.shields.io/badge/license-MIT-blue.svg)
[![Latest Stable Version](https://img.shields.io/packagist/v/sonsuzus/flarum-markdown-tables.svg)](https://packagist.org/packages/sonsuzus/flarum-markdown-tables)

A [Flarum 2.x](https://flarum.org) extension that enables Markdown PipeTables formatting in posts and integrates with the Rich Text editor.

Maintained by [sonsuzus (Ufuk Aksoy)](https://github.com/sonsuzus). Based on the original extension by [Alexander Skvortsov](https://github.com/askvortsov1/flarum-markdown-tables) and [DogSports](https://github.com/DogSports/flarum-ext-pipetables).

## Requirements

- **Flarum:** `^2.0`
- **PHP:** `^8.3`

## Installation

```sh
composer require sonsuzus/flarum-markdown-tables:*
php flarum cache:clear
```

## Updating

```sh
composer update sonsuzus/flarum-markdown-tables
php flarum cache:clear
```

## Frontend Development & Building

```sh
cd js
npm install
npm run build
```
